## 🎯 Objetivos del Proyecto

El objetivo principal de este proyecto es realizar un análisis integral de datos relacionados con las emisiones. Para ello, el proyecto se divide en las siguientes etapas fundamentales:

1. **Extracción, Transformación y Carga (ETL):** Procesamiento de los datos crudos para limpiarlos, estandarizarlos y dejarlos listos para su análisis.
2. **Análisis Exploratorio de Datos (EDA):** Exploración profunda de los datos de emisiones para identificar patrones, tendencias, valores atípicos y correlaciones clave.
3. **Generación de Insights:** Extraer conclusiones accionables que permitan entender el comportamiento de las emisiones a partir de los datos provistos.

## 📁 Estructura del Proyecto

* `Dataset/`: Contiene los conjuntos de datos originales y procesados.
* `ETL/`: Scripts y notebooks enfocados en la limpieza y transformación de los datos.
* `EDA/`: Notebooks (como `EDA_emisiones.ipynb`) dedicados al Análisis Exploratorio de Datos.
